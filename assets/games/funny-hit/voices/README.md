# 狐狐配音接入目录

当前目录 **没有配音音频**。未把 B 站试听视频、游戏角色提取语音或来源不明的下载包复制进仓库。

获得原创录音或允许网站公开发布的授权 TTS 音频后，将文件放在此目录，在 `games/funny-hit/dialogue.js` 的 `F.recordings` 添加精确字幕映射：

```js
// 下面仅为格式示例，不是已存在的文件。
'呜呜，饶了狐狐嘛～': {
  src: 'pleading-01.wav',
  label: '已授权音色名称',
  license: '配音作者、授权日期及许可文件路径'
}
```

只允许本目录内的 WAV/MP3/OGG/M4A 文件名，不接受外站链接。每段最大 2 MB；浏览器最多缓存三段，包括正在播放的录音。预加载下一关键节点，不批量加载全部语音。记录授权和字幕时不要提交 API 密钥。

建议保留 TTS 原生 24kHz/48kHz 母带，完整保存开头和语尾；不要通过反复有损编码或极端升调改善音质。发布前需要实际试听、测量响度与峰值、检查削波和首尾截断。当前没有母带，所以这些音质检查尚未执行。
