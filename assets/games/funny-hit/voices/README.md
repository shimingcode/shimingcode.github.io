# 狐狐配音资源

当前接入用户指定并确认可公开使用的两段原视频女声，来源及范围见 [LICENSE.md](LICENSE.md)。

| 文件 | 时长 | 规格 | 大小 |
| --- | --- | --- | --- |
| xiaosheng-invitation.wav | 6.500秒 | 24kHz / 单声道 / PCM16 | 312,044 B |
| xiaosheng-denial.wav | 4.269秒 | 24kHz / 单声道 / PCM16 | 204,956 B |

游戏默认使用原声，也可在设置中切换系统语音；原声字幕保持原视频内容，不冒充重新配制的狐狐台词。保留视频背景声。加载失败会尝试系统朗读字幕，仍失败则仅显示字幕。

`dialogue.js` 的 `F.recordings` 管理精确字幕与文件名。VoiceManager 复用一个音频元素，最多缓存三段、按需加载，退出时释放。原始视频和转换中间文件仅保存在忽略的 test-results/douyin，不进入发布包。新增资源须记录授权，不提交 API 密钥。
