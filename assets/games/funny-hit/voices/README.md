V2 所有有效点击重播“我才没有！”同一段录音；互动文字独立变化，并非音频逐字字幕。没有修改录音内容、音高或语速。没有 TTS 回退，失败时保留文字和特效。

`dialogue.js` 的 `F.AUDIO_PATH` 统一配置实际文件路径，`AUDIO_VOLUME` 默认为 0.65。VoiceManager 首次用户点击时创建一个音频元素，每次暂停并回到开头，最短重启间隔 150ms；快速点击最多保留一个延迟重启任务。静音、页面隐藏、重置和退出都会取消任务，退出时释放媒体来源。背景音乐由原 CD 播放器独立管理。

原始视频及转换中间文件保存在忽略的 test-results/douyin，不进入发布包。本次没有生成或重新转码任何音频。
