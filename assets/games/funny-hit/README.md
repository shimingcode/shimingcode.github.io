# 人物图片与声音来源

人物照片来自用户在 2026-10-15 提供的「宿舍地板上的搞怪伸展瞬间.png」。只进行了等比缩放与 WebP 编码，没有改变面部、服装、姿势或添加伤口。原始 PNG 保留在用户提供的本地路径，没有改写。网页使用 1086×1448 与 640×853 两种尺寸，按 srcset 选择。

游戏音效是 audio-manager.js 数学合成的原创短音调（Pop、Boing、Combo、铃音），没有从第三方下载声音，没有真实痛苦尖叫。

目前未接入预录狐狐配音，也没有声优授权文件。voice-manager.js 临时检查设备可用的中文 SpeechSynthesis 音色；页面明确展示「临时语音」提示。声音由系统提供，音色、网络需求及可用性因设备而异；没有音色或播放失败时仅显示字幕。它不是照片人物的声音，不模仿指定真人或动漫角色。

未来接入录音时应同时保存作者授权、台词映射和许可说明；没有素材时不要添加虚假的音频路径或宣称已有高质量角色音。
