# 透明面板视觉优化与验收

日期：2026-10-14。基线 `e8da44f83f7aee970b32470f5cde2dd03563ef7d`，开发分支 `codex/transparent-panels`。

## 已实施

- 检查 README、HTML、三份 CSS、主题初始化、播放器、游戏和路由后修改，沿用原生技术栈和布局。
- 在 `css/style.css` 集中定义 `--glass-bg/card-bg/hover/border/border-hover/blur/radius/shadow`，`.glass` 与 `.glass-panel` 共用样式，平台、项目、图库和设置面板复用。透明的是背景，不降低整个组件 opacity，文字、图标和图片保持完整显示。
- 樱花粉面板为白色 12%，平台卡片 10%，悬浮 18%；背景粉白蒙层从约 61% 降到 8%。保留唯一原背景层、原背景位置与 cover 设置，原图片和音乐未修改。
- 星空蓝面板使用蓝黑色 18%，暗夜使用深色 28%；减轻原深色蒙层，保留适度压暗，让浅色文字可读。深色/浅色主题分别设置文字色和局部文字阴影，没有声称按每个图片像素自动识别颜色。
- 桌面通用模糊 4px，首页人物区域 2px；手机分别为 2px/1px。导航大容器与内部卡片不重复加模糊，手机列表卡片关闭模糊。低并发核心/低内存/省流提示只设一个初始化标记，关闭大面板模糊与阴影，不增加动画循环或依赖 UA。
- 播放器控制面板透明，模糊桌面 6px、手机 4px、低性能提示 2px。把原来播放器整个容器的 drop-shadow 移至 CD 按钮，避免创建 backdrop root 导致面板后方文字无法正确模糊。旋转、音量、首次交互播放、循环与跨页播放逻辑未改。
- 游戏信息、选择器、计时区域透明；卡牌保留清晰的实色正面与粉色渐变背面，翻牌仍使用 transform。现有游戏正面是 emoji，未擅自替换为新角色图；现有通关通过状态文本呈现，保留该行为，没有凭空新增弹窗。
- 图库卡片与大图遮罩降低不透明度；保留所有封面和摄影图。原生 select 展开选项、小面积 CD 中心/符号、主要操作按钮和游戏卡牌保持可辨认的实色，并非大面积展示面板。
- 样式、主题初始化和路由脚本更新为 v6；音乐脚本仍为 v5，其他脚本版本保持不变。真实目录 URL、历史导航与 Pages 根目录发布流程不变。

## 视觉和性能检查

使用同机 Edge 隔离上下文，1440×900 与 390×900，樱花粉/星空蓝/暗夜三主题，共六组；保存首页、滚动后的项目区、播放器、游戏、关于和图库截图。另模拟 2 核低性能提示，验证面板模糊降级。人工检查背景人物、标题和正文；修复了初版透明播放器前后文字重叠的问题。

| 项目 | 修改前 | 修改后 |
| --- | --- | --- |
| 樱花粉主面板背景 alpha | 约 0.93 | 0.12 |
| 樱花粉平台卡片 alpha | 约 0.94 | 0.10 |
| 背景粉白蒙层 alpha | 约 0.61 | 0.08 |
| 首页模糊：桌面 / 手机 | 8px / 4px | 2px / 1px |
| 手机列表卡片模糊 | 无 | 无（保持低开销） |
| 每组约 1.5 秒滚动 RAF 采样 | 六组均约 60 FPS | 六组均约 60 FPS |

滚动结果为本机短时实验室采样，系统减少动态效果开启，没有 CPU/网络减速；不是手机真机帧率、Lighthouse 或 INP。桌面卡片新增轻量模糊仍有 GPU 成本，不能宣称总体性能提高。未重新测量 Lighthouse、显存或电量。没有 iPhone/Android/iPad 真机，不把视口模拟说成真机通过。

透明底色受图片区域影响，截图人工检查不等同于全页面像素级 WCAG 对比度认证。以后替换背景图片仍需复核文字对比。页面全高截图中固定背景只出现在拍摄视口范围，滚动后的项目截图用于确认实际滚动时背景仍存在。
