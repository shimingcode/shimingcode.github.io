## 配置

- 默认标准模式、语音 65%、音效 40%，保留用户之前保存的选择。
- 五种情绪 SHY、PLEADING、CUTE、HAPPY、PLAYFUL，每种三条新台词；七个节点映射为惊讶/调皮、害羞、求饶、调皮、撒娇、开心、最终求饶。1 次惊讶是原有指定台词，不额外新增第六种情绪。
- 系统回退采用温和参数，基准语速 .93，各情绪 .91～.98、pitch 1.02～1.06。它只是兼容回退，不是音色设计或专业情绪合成。
- 增加语音试听、五种情绪试听、恢复默认按钮；试听不增加点击数，静音时只显示字幕。情绪选择、音量等保存到 localStorage；恢复默认不重开游戏、不改变 CD 音乐设置。
- `dialogue.js` 的 recordings 表目前为空；支持经授权、按精确字幕映射的本地录音。目录 `assets/games/funny-hit/voices/` 只有接入说明，没有虚构音频文件。

## 调度与资源

一个可复用 HTMLAudioElement 负责本地配音，保持原来的单一 CD 背景音频。仅首次实际需要播放录音时创建配音元素。使用最多三段 blob 缓存，每段 2 MB 上限，8 秒加载超时，退出时 abort、revokeObjectURL、清空媒体 src。按需预取下个关键节点，既无 API 服务端依赖，也不批量下载未使用台词。

普通语音有 2 秒冷却，标准模式普通点击只有音效；关键节点可打断普通语音，关键语音之间采用上限 7 条 FIFO 队列，最终 20 次语音立即抢占并清空过时队列。显式试听会替换旧试听，游戏关键语音优先于试听。字幕只对应当前接受/播放的语音，不把新字幕放在旧配音上。结束后至少保留 700ms，再淡出。正常语音开始后取消启动超时，避免把较长配音中途截断。

页面隐藏清除待播队列、停止语音；离页释放游戏语音缓存与事件。文件失败回退系统语音；播放权限拒绝保留字幕和手动试听，不反复重试。
